\section*{ОБОЗНАЧЕНИЯ И СОКРАЩЕНИЯ}

РИО — редакционно-издательский отдел.

БД — база данных.

СУБД — система управления базами данных.

ORM (Object--Relational Mapping) — технология объектно-реляционного отображения данных.

REST API (Representational State Transfer Application Programming Interface) — программный интерфейс взаимодействия компонентов системы.

JWT (JSON Web Token) — формат токена для аутентификации и авторизации пользователей.

PDF (Portable Document Format) — формат электронных документов.

DOCX — формат текстовых документов Microsoft Word.

HTML (HyperText Markup Language) — язык гипертекстовой разметки веб-страниц.

CSS (Cascading Style Sheets) — язык описания внешнего вида веб-страниц.

SQL (Structured Query Language) — язык структурированных запросов к базе данных.

FastAPI — веб-фреймворк для разработки серверной части приложения на языке Python.

PostgreSQL — объектно-реляционная система управления базами данных.

CRUD (Create, Read, Update, Delete) — основные операции обработки данных.

GUI (Graphical User Interface) — графический пользовательский интерфейс.
API (Application Programming Interface) — программный интерфейс взаимодействия компонентов системы.
