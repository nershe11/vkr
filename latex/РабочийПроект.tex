\subsubsection{Класс User (модель пользователя)}

Класс \texttt{User} (модуль \texttt{models/user.py}) предназначен для представления учётной записи пользователя в системе. Класс используется при аутентификации пользователей, разграничении прав доступа и формировании статистики.

\subsubsection{Модуль проверки документов}

Модуль проверки документов является основным компонентом информационно-аналитической системы и предназначен для автоматизированного анализа учебно-методических материалов на соответствие установленным требованиям оформления.

Модуль реализует загрузку DOCX-документов, их анализ, выявление ошибок форматирования, формирование визуальной разметки нарушений и генерацию итогового PDF-отчёта.

Основная логика модуля реализована в следующих компонентах:
\begin{enumerate}
	\item \texttt{checker.py} — основной модуль проверки документов.
	
	\item \texttt{highlight\_errors.py} — модуль визуального выделения ошибок в документе.
	
	\item \texttt{pdf\_report.py} — модуль формирования PDF-отчётов.
	
	\item \texttt{schemas/checker.py} — схемы валидации входных данных.
\end{enumerate}

\begin{itemize}

	\item формирование PDF-отчётов;

Записи сохраняются в журнале с указанием даты и времени возникновения события.
